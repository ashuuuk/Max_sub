The idea behind the solution

Kadane’s Algorithm

At every index, compare the value on its own with the value added to the previous running sum. Keep whichever is larger. Then update the best sum seen so far. This also handles arrays containing only negative numbers.

current = max(nums[i], current + nums[i])
best = max(best, current)

Time complexity: O(n)
Space complexity: O(1)
